# ptplaner
Configuration for OTP planner

The OTP planner can be accessed here https://ptplanner.latrobe.edu.au

The OTP Planner is configured for several metropolitan areas in Australia. 
The list of metropolitan areas that are covered are listed below:
|City Name | Provider | Data Link | Version |
|--|--|--|--|
|Melbourne|PTV|https://mobilitydatabase.org/feeds/gtfs/mdb-657|31-Mar-25|
|Sydney|Transport for NSW|https://mobilitydatabase.org/feeds/gtfs/mdb-2449|31-Mar-25|
|Brisbane|Translink SEQ|https://mobilitydatabase.org/feeds/gtfs/mdb-668|29-Mar-25|
|Adelaide|Adelaide Metro|https://mobilitydatabase.org/feeds/gtfs/mdb-660|31-Mar-25|
|Perth|TransPerth|https://mobilitydatabase.org/feeds/gtfs/mdb-1169|31-Mar-24|
|Darwin|NA|NA|NA|

|Canberra|NA|NA|NA|
